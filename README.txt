INTERPRETABILITY OF MODEL COLLAPSE
NLP Project 1 (COMS4054A / COMS7062A / COMS7066A)

Code: a fork of the code of Singh et al. (2024), https://github.com/aadityasingh/icl-dynamics
(JAX / Equinox). The model, loss and evaluation code are the paper's; our additions are listed
in section 6. All iteration counts are training SEQUENCES seen (batch size 32), not optimiser steps.

1. REQUIREMENTS
   Python 3.10.   pip install -r requirements.txt
   Training runs need a GPU (one 1M-sequence run: about 10-11 minutes on an RTX 4050 or a
   Colab T4; hours on a CPU). For a GPU, install jax[cuda12]==0.4.26 instead of jax.
   The analysis (interp/) is forward passes only and runs on a CPU.
   notebooks/ holds the Google Colab notebooks we used (A: analysis, B: extended runs,
   C: learning-rate check and recovery runs); each one installs exactly these versions.

2. DATA
   omniglot_resnet18_randomized_order_s0.h5 (in the repository): frozen ResNet-18 embeddings
   of Omniglot characters from Singh et al. (2024). No other data is needed; every training
   pool is generated by the code (pool seed 10).

3. RUN (from the repository folder)
   Base version, generation 0 and the four collapse conditions (about 6 GPU hours):
     python main.py <TRAIN_ARGS from run_generations.sh> --train_iters 1000000 --eval_every 5000 \
         --ckpt_every 1000 --init_seed 5 --pool_size 1000000 --base_folder collapse --run gen0_pool
     cp collapse/gen0_pool/pool_gen0.h5 collapse/pool_gen0.h5
     bash run_all_conditions.sh
   Extended version (learning rate chosen on the validation set, see notebook B):
     LR=<chosen> bash run_extended_conditions.sh
   Phase timing of any run:
     python find_phases.py <run folder> --metric fsl_val_rl/in_context_acc
   Q1 analysis (induction circuit as an early warning):
     python test_interp_heads.py collapse/gen0_pool
     python -m interp.find_heads_gen0 collapse/gen0_pool --out results/interp/gen0_base
     python -m interp.track_generations --run sample_T1=collapse/gen0_pool:collapse/sample_T1 \
         [--run ... one per condition] --gen0-json results/interp/gen0_base/gen0_heads.json \
         --out results/interp/tracking_base --within-training 1
     (extended: the same two commands on collapse_ext/gen0_p50 and collapse_ext/T1, collapse_ext/argmax)
   Learning-rate checks and the optional recovery runs (Q2): notebook C.

4. TESTS
     python test_interp_heads.py [collapse/gen0_pool]   analysis code (the argument adds a check
                                                       against a trained run's own log)
     python test_extended_sampler.py                    extended sampler (more in test_extended_*.py)

5. OUTPUTS
   collapse/, collapse_ext/   run folders: config.json, log.h5 (all evaluation metrics),
                              checkpoints/ (every 10,000 sequences), pools and pool summaries.
                              Not in git (too large).
   results/interp/gen0_*/     head identification: gen0_heads.json, heatmaps, attention patterns
   results/interp/tracking_*/ tracking.csv (per generation), early_warning.csv (Q1 across
                              generations), within_training.csv and formation.csv (Q1 within
                              training), figures
   results/lr_sweep_*.csv     learning-rate selection on the validation set
   results/extended_drift/    analyze_extended.py output for the extended version

6. WHAT WE ADDED TO THE PAPER'S CODE
   samplers.py, main_utils.py, main.py (changed): fixed training pool, extended version
   relabel.py, run_generations.sh, run_all_conditions.sh, run_extended_conditions.sh,
   find_phases.py, analyze_extended.py, check_extended_run.py, compare_runs.py,
   test_extended_*.py (new): collapse pipeline and extended version
   interp/, test_interp_heads.py (new): Q1 analysis
   notebooks/ (new): Colab notebooks
